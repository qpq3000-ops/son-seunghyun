# 설계 — 거래명세서인쇄 (이카운트 실화면 3장 기준, 2026-07-11 사용자 제공)

> 이카운트의 [재고Ⅰ > 영업관리 > 판매 > 거래명세서인쇄] 전체 동선을 재현한다.
> 우리의 기존 PrintDoc(전표 1건 인쇄)과 달리, 이 메뉴는 **기간×거래처 단위의 합산 명세서**다
> — 입금주기 '월별' 거래처에게 월말 정산 명세서를 발행하는 실업무 핵심 기능.
> 도장 이미지·이카운트 고유 그래픽은 재현하지 않는다. 개인정보(사업자번호/계좌/성명)는 코드에 넣지 않고 환경설정에서 입력받는다.

## 화면 1: 검색 화면 (menus id: statement-print, 영업 그룹, 이름 "거래명세서인쇄")
- 검색조건 카드 (이카운트 배치 그대로, 세로 라벨-필드):
  - **기준일자**: [금월(~오늘)] pill + 시작일 ~ 종료일 (기본: 이번달 1일 ~ 오늘)
  - 거래처 (코드도움, 비우면 전체)
  - 품목 (코드도움, 선택)
  - 기타: ☐ 미수금집계 (체크 시 리스트에 전잔/미수 컬럼 추가)
- 하단 버튼 바 (이카운트 순서): **[검색(F8)]**(파란) [금일] [전일] [금주(~오늘)] [전주] [금월(~오늘)] [전월] [다시 작성]
  - 기간 프리셋 버튼: 클릭 시 기준일자 범위 변경 후 즉시 검색
  - F8 키 바인딩 = 검색 (이 화면은 입력 폼이 없으므로 저장과 충돌 없음)

## 화면 2: 거래명세표리스트 (검색 결과)
- 상단 중앙 큰 제목 "거래명세표리스트", 좌측 "회사명 : {settings.company_name}", 우측 "{시작일} ~ {종료일}"
- 그리드 (거래처별 1행 합산):
  | 거래처명 | 품목명[규격명] (첫 품목 + "외 N건") | 수량 | 금액(공급가액) | 부가세 | 합계 | 상세 |
- 하단 합계행 (전체 수량/금액/부가세/합계)
- [상세] 클릭 → 화면 3 팝업
- 하단 버튼: [인쇄] (리스트 자체 인쇄, @media print)
- 데이터: 기간 내 sale 전표를 거래처별 group by. API: GET /api/statements?from&to&partner_id&item_id → [{partner_id, partner_name, item_summary, line_cnt, qty, supply, vat, total}]

## 화면 3: 거래명세서 팝업 (거래처 1곳의 기간 명세서)
- 모달: 파란 타이틀바 "거래명세서" + 닫기 (이카운트 팝업 스타일)
- 양식 본문 (A4 인쇄 대상):
  - 중앙 제목 "거래명세서"
  - 좌측 박스: "{거래처명} 貴中" + 거래처 주소/전화
  - 우측 공급자 박스: 일련번호(마지막 전표번호), 사업자등록번호(settings.company_biz_no), TEL(company_phone), 성명(company_ceo), 상호(company_name), 주소(company_address) — 표 형태 2열
  - **금액 행**: "금 액 : {한글금액}원 정   (₩{숫자})" — 한글 금액 변환 유틸 필요 (예: 827200 → 팔십이만칠천이백)
  - 품목표: **일자** | 품목명[규격] | 수량(단위포함, 예: 12ea→12kg) | 단가 | 공급가액 | 부가세
    - 기간 내 해당 거래처의 모든 판매 라인을 일자순으로 나열 (전표 여러 건 합침)
  - 합계행: 수량 | 공급가액 | VAT | 합계 | 인수(서명란 "인")
  - 전잔/후잔 행: 전잔 = 기간 시작 전 미수 잔액, 후잔 = 전잔 + 기간 매출 - 기간 수금 (receivables 로직 재사용)
  - 하단 입금 계좌 박스: settings 신규 키 `bank_account_info` (여러 줄 텍스트: 예금주/계좌번호/인사말) — 환경설정 화면에 textarea 추가
- 팝업 하단 버튼: [인쇄](파란, window.print) [Excel] [닫기]
- API: GET /api/statements/:partnerId?from&to → { partner, lines:[{io_date, item_name, spec, qty, unit, price, supply, vat}], totals, prev_balance, after_balance }

## 서버 추가 (reports.mjs 또는 신규 statements.mjs)
