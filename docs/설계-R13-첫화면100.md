## 0. 대원칙 (R13 불변 규칙)

- **이모지 문자 사용 절대 금지**(사용자 확정 §13.6-4). 화면에 나오는 그림 이모지(컬러 글리프)는 전부 **인라인 SVG 또는 CSS 도형**으로 교체. 단, **순수 도형문자**(`▼ ▲ ✕ ✓ ● ⬇` 등 — 실물도 사용)는 유지. **예외: `★`은 지시상 SVG로 교체**(§13.6-4, 실물도 노란 별).
- `client/src/styles.css`는 **append-only** — 파일 **끝에 `R13` 블록 하나만** 추가. 기존 줄 수정 금지. 기존 클래스(`hdr-*`, `widgets.mp6`, `star`, `r8-star`, `favbar-pin`, `logo`, `mypage-head`, `widget-icons`) **재사용/override 우선**.
- 기존 메뉴 **id 동결**(삭제·개명 금지). **라벨(name·group 표시문자열) 변경만 허용.**
- 금액 INTEGER(원) / 수량 REAL(kg). 그리드는 DataGrid(Tabulator). 국세청/은행/전자결재 등 실연동은 **동작 없는 stub**(`disabled`+`title`) 유지.
- **App.tsx 수정 시 `groupItems→subgroup` 파생 불변식 유지** — MENUS/`activeGroup`/`subgroups`/`sideItems` 로직은 손대지 않고, ① 로고 마크업 ② favbar-pin/검색 아이콘 ③ 즐겨찾기 시드 초기화만 교체(메뉴 사라짐 방지).
- **신규 마이그레이션 0건, 서버 변경 0건, 신규 npm 의존성 0건.** 검증 중 **서버 기동·포트 8010 금지**, **git 커밋 금지**, 코드·문서에 **모델명/AI 식별자 금지**.

## 2. A. 로고 워드마크 (ECOUNT식: 빨강 스트라이프 E + COUNT 회색 볼드)

실물 구조: 왼쪽 **빨간 가로줄무늬 'E' 심볼**(수직 기둥 + 상/중(짧음)/하 3개 가로 바 → 사이의 흰 간격이 줄무늬) + **볼드 대문자 워드**(진회색 #333). 높이 ~26px. 정확한 상표 복제가 아니라 **동일 시각 구조**를 인라인 SVG로 재현한다.

### 2.1 App.tsx — 로고 버튼 내부 교체
기존(107~111행 근처):
```tsx
<button className="logo" onClick={() => open('dashboard')}>
  <span className="logo-mark">☕</span><b>로스팅</b>ERP
</button>
```
→ 교체:
```tsx
<button className="logo" onClick={() => open('dashboard')} aria-label="ECOUNT 홈">
  <svg className="brandmark" viewBox="0 0 132 30" role="img" aria-label="ECOUNT">
    {/* 빨강 스트라이프 E 심볼 */}
    <rect x="2"   y="3"    width="5.5" height="24"  rx="1.4" fill="#e5231b" />
    <rect x="2"   y="3"    width="20"  height="5.2" rx="1.4" fill="#e5231b" />
    <rect x="2"   y="12.4" width="15.5" height="5.2" rx="1.4" fill="#e5231b" />
    <rect x="2"   y="21.8" width="20"  height="5.2" rx="1.4" fill="#e5231b" />
    {/* COUNT 회색 볼드 */}
    <text x="29.5" y="22.6" fontFamily="'Malgun Gothic',Arial,sans-serif"
          fontSize="22" fontWeight="800" letterSpacing="0.4" fill="#333">COUNT</text>
  </svg>
</button>
```
> 기존 `.logo-mark` CSS(19px)는 미사용으로 남아도 무해(삭제 금지 — append-only). `<b>`도 제거됨.

### 2.2 styles.css(R13) — 로고 크기
```css
.logo .brandmark { height: 26px; width: auto; display: block; }
```
`.logo`의 `font-size/color/gap`은 SVG-only 자식이라 영향 없음(수정 불필요).

## 6. E. 대메뉴 라벨 로마자화 (Ⅰ/Ⅱ → 공백+영문)

**핵심 주의**: 그룹 문자열(`'재고Ⅰ'` 등)은 **표시 라벨이자 조인 키**다 — ① `m(id, group, …)`의 `group` 필드 ② `MENU_GROUPS` 배열 ③ `SUBGROUP_ORDER` 키, 그리고 App.tsx의 `x.group === activeGroup`·`SUBGROUP_ORDER[activeGroup]`·`x.group.includes(t)`에서 비교된다. **세 곳을 함께 바꾸면 참조 정합이 유지**된다(그룹은 localStorage/DB에 저장되지 않음 — 즐겨찾기는 id 기반이라 안전).

### 6.1 menus.tsx — 정확 토큰 4종만 일괄 치환(replace all)
| 기존 | 변경 |
|---|---|
| `재고Ⅰ` | `재고 I` |
| `재고Ⅱ` | `재고 II` |
| `회계Ⅰ` | `회계 I` |
| `회계Ⅱ` | `회계 II` |

- 반드시 **정확 토큰**으로 치환(에디터 replace-all, 대상 문자열 그대로). 이 4토큰은 menus.tsx에서 **그룹 라벨(과 주석)에만** 등장한다.
- **절대 `Ⅰ`/`Ⅱ` 단독 치환 금지** — 메뉴 *이름*의 `매출전표Ⅰ`·`매입전표Ⅰ`·`거래처관리대장Ⅰ/Ⅱ`(문서명, 실물도 Ⅰ/Ⅱ 유지)를 깨뜨림. 위 4토큰은 이 이름들의 부분문자열이 아니므로 안전.
- 치환 대상은 (a) 약 200개 `m(...)`의 group 인자, (b) `MENU_GROUPS` 배열의 해당 4항목, (c) `SUBGROUP_ORDER`의 해당 4개 **키** — replace-all이면 전부 동시에 잡힌다.

### 7.2 App.tsx — 초기화 로직(1회성 시드, 이후 사용자 변경 유지)
기존:
```tsx
const FAV_KEY = 'erp_favorites';
...
const [favs, setFavs] = useState<string[]>(() => {
  try { return JSON.parse(localStorage.getItem(FAV_KEY) || '[]'); } catch { return []; }
});
```
→ 교체:
```tsx
const FAV_KEY = 'erp_favorites';
const FAV_SEEDED = 'erp_favorites_seeded';   // 기본 시드 1회 표식
const FAV_SEED = [
  'stock-status', 'partner-acct', 'prod-in', 'sale-status', 'statement-print',
  'ar-by-partner', 'sale-bulk-acct', 'e-tax-invoice', 'bank-link', 'gl-voucher',
];
...
const [favs, setFavs] = useState<string[]>(() => {
  try {
    const stored = JSON.parse(localStorage.getItem(FAV_KEY) || '[]') as string[];
    if (!localStorage.getItem(FAV_SEEDED)) {          // 최초 1회
      localStorage.setItem(FAV_SEEDED, '1');
      if (!stored.length) return FAV_SEED;            // 비어 있으면 실물 10종 시드
    }
    return stored;                                    // 이후엔 저장값 그대로(사용자 변경 유지)
  } catch { return []; }
});
```
동작: ① 최초 로드(표식 없음)+즐겨찾기 비어 있음 → 10종 시드 ② 이미 즐겨찾기 보유 → 그대로 유지 ③ 시드 후 사용자가 지우면 → 표식이 있어 **재시드 안 함**(사용자 선택 존중). 기존 `useEffect(localStorage.setItem(FAV_KEY, …))`가 시드값을 저장.

### 7.3 힌트 문구
App.tsx:102 `{!favs.length && <span className="favhint">…★…</span>}`는 **조건이 이미 `!favs.length`** → 시드로 즐겨찾기가 생기면 자동 숨김(§13.6-3 충족). 별도 수정 불필요.
