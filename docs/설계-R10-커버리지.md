## 0. 현행 코드 파악 (설계 전제)

- **menus.tsx**: `MenuDef{ id, group, name, component, phase, implemented, subgroup? }`. 헬퍼 `m(id, group, name, phase, component?, subgroup?)`, 미구현은 `ph()`, '연동 예정'은 `stub()`(공용 StubScreen), 보고서는 `R(id)`(REPORT_DEFS 조회). `MENU_GROUPS`(대메뉴 9개), `SUBGROUP_ORDER`(현재 재고Ⅰ만). 현재 81개 메뉴.
- **App.tsx (수정 금지 — 두 패키지 모두 건드리지 않음)**: 서브탭·사이드바를 `groupItems.map(x=>x.subgroup)`에서 **파생**한다.
  - ⚠️ **완결성 불변식**: 어떤 대메뉴에 서브그룹을 도입하면, 그 대메뉴의 **모든** 메뉴가 서브그룹을 가져야 한다. `sideItems = groupItems.filter(x => x.subgroup === activeSubgroup)` 이므로, 서브그룹이 없는 항목은 사이드바에서 **사라진다**. → 회계Ⅰ 등에 서브그룹을 새로 넣을 때 기존 항목 전부에 subgroup을 배정할 것(패키지 B의 핵심 작업).
  - `SUBGROUP_ORDER[group]`가 있으면 그 순서로 서브탭을 그림. 없으면 등장순. `MENU_GROUPS`에 그룹을 추가하면 대메뉴 탭이 자동 추가됨. 즉 **menus.tsx만 고치면 App.tsx 수정 없이** 서브탭·대메뉴가 확장된다.
- **StubScreen.tsx**: 🔌 "연동 예정" 박스(은행/WMS/POS 등 미래 연동용). → R10 "메뉴 뼈대" 용도로 **부적합**(과업이 '준비 중' 아님을 명시). 신규 **GridStub** 컴포넌트를 만든다.
- **Placeholder.tsx**: 🚧 "Phase N에서 구현" 박스. 역시 뼈대용 아님.
- **ReportScreen.tsx + reportDefs.ts**: `ReportDef{ id,title,endpoint,filters,columns,summaryLine,real? }`. `real` 옵션(중앙 24px 제목/회사명 줄/음수셀 #F2DEDE/하단버튼)까지 있음. 서버 report 엔드포인트는 `{rows, summary}` 또는 원장형 env를 반환. `R(id)`로 마운트.
- **DataGrid**: `data=[]`이면 placeholder '자료가 없습니다' 표시 → 빈 그리드 뼈대에 그대로 사용.
- **VoucherList.tsx (SaleList/PurchaseList)**: R8 실물 타이틀바(★/상태 pill/Search(F3))·리스트바(페이저·기간)·기간검색·엑셀만 존재. 하단 버튼 10종·행별 '조회'·'불러온전표' 컬럼 **없음** → R10-A 대상. 행 더블클릭 → `setEditId` → `VoucherScreen(mode="edit")` 교체가 이미 됨(=행 열람 로직 재사용 가능). `VoucherScreen`은 `mode:'create'|'edit'` 지원(신규 버튼에 재사용).
- **SettingsScreen.tsx**: 회사정보/업무설정/이카운트연동/데이터 4섹션. 카테고리 탭 없음 → R10-A 대상.
- **settings API**(masters.mjs): `GET /api/settings`(전 key→value) / `PUT /api/settings`(임의 key upsert). **신규 key 자유 저장 가능 → 서버 변경 불필요.**
- **doc 테이블**: `source_doc_id`(끌어오기 원본) 존재. `/api/docs` 리스트 SELECT엔 미포함 → '불러온전표' 실데이터를 쓰려면 vouchers.mjs에 컬럼 2개만 **가산**(선택, 아래 A-3).

### A-2. 기능설정 실물화 (SettingsScreen.tsx)

실물(§11 Self-Customizing > 환경설정 > 기능설정): **카테고리 탭(공통/회계/재고/관리/그룹웨어/데이터센터) + 설정 카드**. 기존 4섹션을 카테고리로 재배치하고, 실측 기본값 카드를 추가한다.

| 탭 | 카드(설정 key / 기본값) |
|---|---|

### A-3. (선택·권장) server/vouchers.mjs 가산 — '불러온전표' 실데이터

`GET /api/docs` 리스트 SELECT에 원본 전표 조인 **가산**(기존 필드·소비자 불변, 필드 2개만 추가):

```sql
-- FROM 절에 추가
LEFT JOIN doc src ON src.id = d.source_doc_id
-- SELECT 절에 추가
d.source_doc_id, src.doc_no AS source_doc_no
```

`return c.json(rows.map(...))`에 그대로 실려 나감. 미적용 시 A-1의 컬럼은 빈 셀(graceful) — **A는 이 파일 없이도 컴파일·동작**. 서버 신규 API 아님(기존 엔드포인트 컬럼 가산).

### B-2. 서브그룹 도입 + 기존 항목 완결 배정 (App.tsx 불변식 준수)

아래 그룹에 서브그룹을 도입한다. **각 그룹의 기존 항목 전부**에 subgroup을 배정(누락 시 사이드바에서 사라짐). `SUBGROUP_ORDER`에 순서 추가(실물 §11 순서).
