## 2. MyPage 대시보드 (실물 배치 — 최우선 구현)

헤더: `< 2026/07 > 일정관리` (연/월 네비) + 우측 아이콘(↗ ✎ ⋮).
**3열 배치** (폭 비율 약 34% : 20% : 41%):

| 열1 | 열2 | 열3(넓음) |
|---|---|---|
| 재고현황 | To Do | 판매현황 |
| 쪽지함리스트 | (세금)계산서진행단계 → 열2~3 가로 스팬 | 매입매출장 |

- **재고현황 위젯**: 품목코드(파랑 링크) / 품목명[규격] / 재고수량(우측정렬, 음수도 검정). 규격 없으면 `[kg]`처럼 단위 표기가 붙음. 행 줄무늬(짝수행 연회색 #F7F8F9).
- **판매현황 위젯**: **전표의 품목 줄 단위**로 행 생성(같은 "2026/07/02 -1"이 품목별로 반복). 컬럼: 일자-No.(파랑 링크) / 품목명[규격] / 수량 / **단가** / 공급가액 / 부가세 / 합계 / 거래처명. 단가 = 공급가액÷수량 반올림 표기(실물: 3,230,000/114=28,364).
- **To Do**: 없으면 "등록된 데이터가 없습니다." (실물 문구)
- **쪽지함리스트 / 매입매출장 / (세금)계산서진행단계**: 이 회사 데이터 없음 → 제목 + "등록된 데이터가 없습니다." 형태. 쪽지함은 그룹웨어 쪽지(수신 최근 N건), 매입매출장은 회계Ⅰ 매입매출장 최근 행, 계산서진행단계는 세무 위젯.
- 클론의 기존 '미수금 TOP'·'달력 미니' 위젯은 **기본 화면에서 제외**(코드는 보존 — 추후 위젯 설정 기능용).

## 3. 재고현황 (재고Ⅰ>출력물, E040701)

검색폼은 기존 R7-b 매칭 유지. **결과 화면을 실물화**:
- 타이틀바: ★ 재고현황 (좌) / 우측: [입력 후 [Enter]] 인풋 + `Search(F3)` 파랑버튼 + Option + 도움말
- 본문 상단: 가운데 24px 굵은 제목 "재고현황", 그 아래 좌 "회사명 : 블랙크랙원 로스터스"(환경설정 상호) / 우 기준일 "2026/07/12"
- 그리드 3열: 품목코드▼(가운데 머리글, 셀은 파랑 링크) / 품목명[규격]▼(좌) / 재고수량▼(우). **음수 재고 셀 배경 #F2DEDE**
- 하단 버튼: `인쇄`(파랑 스플릿+▲) / `Excel` / `자동알림`

## 4. 판매조회 (재고Ⅰ>영업관리, E040206)

- 타이틀바: ★ 판매조회 + 상태 pill 필터 [**전체**(파랑 채움)/결재중/미확인/확인] + [입력 후 Enter] + `Fn` + `Search(F3)` + Option + 도움말
- 그 아래줄: 페이지네이션 `① 2 » [입력]/2` (좌) + 조회기간 표기 "2026/06/01 ~ 2026/07/12" (우)
- 그리드 컬럼: [체크박스] / 일자-No.(파랑 링크, "2026/07/09 -3" 형식) / 거래처명 / 품목명(요약)("bco 블랜딩 [kg] 외 1건") / 금액합계(우측) / 거래유형명("부가세율 적용") / 창고명 / 회계반영여부(초록 ✓) / 인쇄(링크·인쇄완료분은 주황 배지)
- 순번: 회색 테두리 사각 배지(1,2,3…). 행 높이 큼(셀 멀티라인 허용), 모든 셀에 옅은 보더.
