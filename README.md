# 로스팅 ERP — 이카운트 클론 프로젝트

1. Claude Code에서 모델을 Opus 4.8로 설정
2. `docs/03-오퍼스-작업-프롬프트.md`의 **① 마스터 프롬프트**를 붙여넣어 Phase 0 시작
