## 실행 방법 (Phase 0 구현 완료)

**Windows**: `시작.bat` 더블클릭 → 자동으로 설치·빌드 후 브라우저가 열립니다.

수동 실행:

```bash
npm install   # 최초 1회
npm start     # http://localhost:8010
```

- 데이터: `data/erp.sqlite` 단일 파일 (서버 시작 시 `data/backup/`에 자동 백업, 최근 30개)
- 개발 모드: `npm run dev:server` + `npm run dev:client` (Vite HMR, localhost:5173)

## 데이터 이관 / 이카운트 연동

- **엑셀 이관**: 이카운트에서 내려받은 품목(`ESA009M.xlsx`)/거래처(`ESA001M.xlsx`)를 `data/import/`에 넣고 `node scripts/import-ecount-excel.mjs` 실행 (재실행 안전, 코드 기준 upsert)
- **API 연동(조회 전용)**: `data/ecount.config.json`에 접속정보(COM_CODE/USER_ID/API_CERT_KEY/MODE)를 넣으면 [설정] 화면에서 품목 동기화 가능. 이카운트에 등록된 공인 IP의 PC에서 실행해야 동작. **인증키는 절대 커밋 금지** (`data/`는 gitignore 처리됨)
- **사내 공유**: 서버 실행 후 같은 네트워크에서 `http://<실행 PC의 IP>:8010` 접속
